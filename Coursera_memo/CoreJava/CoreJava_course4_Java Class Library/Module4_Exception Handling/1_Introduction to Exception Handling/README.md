# 1. 예외 처리 소개
***
- Java가 런타임 예외를 처리하는 방법 (0으로 나누기 오류, 자체 어플리케이션 오류, IO오류 등)
- try/catch 구문
- Checked 예외와 Unchecked 예외
- 예외를 정의하는 법
***
C같은 경우 에러가 발생했을 때 null이나 음수값의 정수를 반환한다

하지만 코드가 어떤 값이라도 반환할 수 있다면? void 반환을 가지고 있다면? 오류를 전달할 수 있는 수단을 가지도록 코드를 설계해야 한다.

호출할 때마다 반환 값, 파라미터, 글로벌 오류 코드를 검사하는 등 매번 오류가 발생했는지 확인해야 한다.
***
### **Java는 이러한 불편함이 없다!**

*try/catch* 블럭을 이용해 try해보고 싶은 코드 구문에 예외가 발생하면, catch 블록을 통해 예외를 처리할 것

메서드에 에러가 발생할 때, _throw_ 키워드를 이용해 **Exception 클래스의 새 인스턴스**를 만든다. 그 후 이 객체를 **메서드를 호출한 코드에 전달**하여 catch 블록에 의해 처리될 것이다.
