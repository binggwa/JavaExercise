# 1. Intro
***
- 이동 영업 사원 문제(TSP)를 설명
- TSP를 (최적 및 비최적) 해결하기 위한 몇 가지 알고리즘을 설명
- 알고리즘이 TSP를 최적으로 푸는지 분석
- 여러 TSP 알고리즘의 실행 시간 분석
- NP-하드 문제의 개념 설명
- NP-Hard 문제 식별의 가치(및 한계)를 설명
- 휴리스틱을 사용하여 어려운 문제에 대한 합리적인 해결책 찾기
- 2옵션 휴리스틱을 TSP에 적용
- 그래프에서 해밀턴 순환 정의
- 작은 예를 들어 그래프가 해밀턴인지 아닌지 결정
- 그래프가 해밀턴인지 여부를 결정하는 알고리즘을 설명하고 그 효율성을 분석
- 그래프에서 오일러 회로를 정의
- 작은 예에서 그래프가 오일러인지 여부를 결정
- 그래프가 오일러인지 여부를 결정하는 알고리즘을 설명하고 그 효율성을 분석
***
### TSP(NP-Hard 문제) 해결을 위한 알고리즘 후보 
- 탐욕(Greedy) 알고리즘 : 원래 노드로 돌아올 때까지의 글로벌한 경로를 고려하지 못함
- 무차별 대입(Brute-Force) 알고리즘 : 노드 수가 많아질수록 경우의 수가 기하급수적으로 늘어남
- 근사치와 휴리스틱 : 2-Opt 휴리스틱을 이용해 효과적인 해를 찾아가는 대안을 제시
***
### 해밀턴 그래프
- 각 정점을 정확히 한 번씩 포함하는 정점의 어떤 시퀀스가 있고 그 시퀀스의 연속 정점이 그래프의 가장자리로 연결되는 그래프
### 오일러 그래프
- 해밀턴 그래프의 조건이 정점이 아닌 edge가 되는 그래프
