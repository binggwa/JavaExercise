# 1. Intro
***
- 가중치가 없는 그래프에 대한 넓이 우선 검색의 값 설명
- 가중치가 있는 가장자리가 있는 그래프에 대한 넓이 우선 검색의 한계 설명
- 가중 그래프에 다익스트라의 알고리즘 적용
- 다익스트라 알고리즘을 구현하는 코드를 작성
- ADT 우선순위 큐의 작동 방식 설명
- 다익스트라 알고리즘에서 우선순위 큐가 어떻게 사용되는지 설명
- 다익스트라 알고리즘의 한계 설명
- 가중 그래프에 A* 검색 알고리즘 적용
- A* 검색을 위한 코드 작성
