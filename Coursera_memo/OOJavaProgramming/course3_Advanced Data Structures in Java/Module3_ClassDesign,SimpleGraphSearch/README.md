# 1. Intro
***
- 2D 미로 문제를 그래프로 표현하는 방법 설명
- 지리적 지도를 그래프로 표현
- 그래프에서 깊이 우선 검색(DFS) 및 넓이 우선 검색(BFS) 수행
- DFS와 BFS를 위한 코드 구현
- DFS와 BFS의 최악의 경우 실행 시간 분석 및 비교
- ADT 스택과 큐의 작동 방식 설명
- DFS에서 스택이 사용되는 방법과 BFS에서 큐가 사용되는 방법 설명
- 그리드 기반 그래프를 표현하는 클래스 설계
- 재설계와 리팩터링의 개념 설명
- 코드 설계의 측면 비판
- 더 나은 디자인을 위한 코드 재설계 및 리팩터링
***
### 좋은 디자인을 위해 봐야 하는 것
- 객체들이 이해가 되는지, 데이터와 메소드가 함께 있는지
- 인터페이스가 깔끔하고 private 데이터가 노출되어 있지 않은지
- 우리가 원하는 작업을 쉽고 빠르게 수행할 수 있는지
- 메서드가 짧고 읽기 쉬우며 이해하기 쉬운지
