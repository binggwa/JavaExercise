# 1. Intro
***
- Java에서 그래프를 처음부터 구현
- 다양한 그래프 구현의 성능을 분석
- 다음을 포함한 기본 데이터 구조에 대한 Java의 기본 제공 클래스로 작업: 해시셋, 해시맵, 우선순위 큐를 포함한 기본 데이터 구조
- 필드, 메서드 및 상속 관계를 포함한 고수준 프로세스를 해결하기 위한 클래스를 설계
- 그래프 검색을 위한 여러 알고리즘을 설명하고 구현
- 다양한 컨텍스트에서 다양한 그래프 검색 알고리즘의 성능을 평가
- 그래프와 그래프 알고리즘을 사용하여 실제 데이터를 사용하여 경로를 계획
***
# 학습 결과
- Java로 그래프를 구현하는 클래스 설계
- 폭 우선 검색구현
- Dijkstra의 알고리즘
- A* 검색을 포함한 기본적인 그래프 검색 알고리즘
- 실제 지리적 도로 데이터로 작업
