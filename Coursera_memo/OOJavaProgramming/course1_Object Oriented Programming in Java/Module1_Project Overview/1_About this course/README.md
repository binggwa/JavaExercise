# 1. 코스에 대한 개요
***
1. Java로 클래스를 작성하고 객체가 어떻게 구성되는지, 객체가 데이터를 저장하는 방법, 객체의 동작을 정의하는 방법을 설명할 수 있다.
2. 메모리 모델을 사용하여 코드 실행을 추적한다.
3. 변수와 메서드의 범위를 정의한다.
4. 기존 라이브러리를 확장하여 중간 규모의 프로젝트를 구축한다.
5. 사용자 인터페이스 기능을 구현한다.
6. 여러 레벨이 있는 클래스 계층 구조를 구축하고 작업한다.
7. 객체 간의 "is-a" 및 "has-a" 관계를 설명한다.
8. 인터페이스를 구현하는 코드를 작성한다.
9. 다형성으로 작업할 때 컴파일 타임과 런타임 결정의 차이점을 설명한다.
10. 이벤트 중심 프로그래밍과 명령형 프로그래밍의 차이점을 설명할 수 있다.
11. 검색과 정렬을 사용하여 데이터 분석을 위한 알고리즘을 설계한다.
12. 정렬된 목록과 정렬되지 않은 목록에서 요소를 검색하고 차이점을 설명한다.
13. 여러 가지 정렬 기법과 성능 트레이드오프에 대해 설명한다.
***
# 2. 프로젝트 개요
***
- Java로 대화형 그래픽 프로그램 빌드
- 객체 지향 프로그래밍 패러다임을 활용하는 클래스 디자인
- 상속과 다형성을 설명하고 각 개념이 Java GUI를 만들 때 어떻게 적용되는지 설명
- Java에서 이벤트 처리가 어떻게 작동하는지 설명하고 이벤트 핸들러를 작성하여 대화형 프로그램을 만든다
- 대규모 데이터 세트를 관리하기 위해 검색 및 정렬 알고리즘을 작성하고 적용한다
- 코드에서 오류(버그) 찾기 및 수정
- 프로그램의 정확성을 보장하기 위해 테스트 케이스 개발 및 사용
