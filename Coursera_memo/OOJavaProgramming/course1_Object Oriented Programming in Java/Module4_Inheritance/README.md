# 1. 모듈 목표
***
- 객체 지향 프로그래밍 언어의 기능으로서 상속의 가치 설명
- 키워드 확장 사용
- 수퍼클래스와 서브클래스 사이의 관계 설명
- UML 다이어그램을 사용하여 클래스 계층 구조 표시
- 클래스 간의 "is-a" 관계 설명
- Java 객체 구성이 내부에서 외부로 어떻게 발생하는지 설명
- 클래스 생성 시 동일 클래스 및 수퍼클래스 생성자 사용
- 수퍼클래스에서 재정의하는 메서드 생성
- 메서드 오버로딩과 메서드 오버라이딩 대조
- 다형성의 목적 설명
- 컴파일 타임과 런타임에 내린 결정을 단계별로 살펴보기
- 컴파일러를 돕기 위해 객체 형변환 사용
- "추상" 키워드 사용
- "구현 상속"과 "인터페이스 상속" 비교 및 대조
- 추상 클래스와 인터페이스 중 어떤 것을 사용할지 결정
