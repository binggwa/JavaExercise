# 1. Intro
***
- 추상 데이터 유형(ADT)과 그 구현의 차이점을 설명할 수 있다.
- String, LinkedList, TreeSet, HashSet 및 HashMap을 포함한 기본 데이터 구조에 대한 기본 제공 클래스로 작업할 수 있다.
- Linked Lists 및 Tries를 포함한 기본 데이터 구조를 처음부터 구현
- 지정된 인터페이스 구현
- 벤치마킹을 수행하여 코드 실행 시간 측정
- 벤치마킹 테스트 결과를 Big-O 분석과 연관
- Big-O 표기법을 사용하고 벤치마킹 실험을 통해 코드의 성능을 분석
- 다양한 데이터 구조의 성능을 비교하고 대조하여 작업에 가장 적합한 데이터 구조를 선택
- 코드의 정확성을 보장하기 위해 JUnit 테스트를 작성
- 텍스트 생성 및 처리를 위한 여러 알고리즘을 구현
