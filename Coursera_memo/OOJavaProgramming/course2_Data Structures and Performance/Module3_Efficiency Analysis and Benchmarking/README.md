- 점근 분석이 유용한 이유 설명
- 코드 조각의 big-O 클래스 계산
- 더 작은 코드 조각의 런타임을 결합하여 더 복잡한 코드의 성능 분석
- 중첩 루프가 있는 코드의 big-O 클래스 계산
- 선택 정렬의 성능 분석
- 최악의 경우, 평균적인 경우, 최상의 경우의 성능을 정의하고 각각의 성능을 사용하는 이유를 설명
- 선형 검색, 이진 검색, 선택 정렬 및 삽입 정렬의 점근 성능을 최상의 경우와 최악의 경우의 점근 성능을 명시하고 정당화
- 병합 정렬 알고리즘을 설명
- 병합 정렬에서 재귀의 사용 설명
- 점근 분석을 사용하여 병합 정렬과 선택 정렬 및 삽입 정렬을 비교
- 삽입 정렬, 선택 정렬, 병합 정렬 및 빠른 정렬의 최고, 최악 및 평균 성능을 설명
- 다양한 정렬 알고리즘이 적절한 상황 평가
- 성장률에 따라 큰-O 클래스 구성
- 점근 분석의 일반적인 함정 피하기
- 컴퓨터 과학에서 벤치마킹의 역할 설명
- 실행 시간에 영향을 미치는 실제 시스템의 구성 요소 식별
- Java 타이밍 라이브러리를 사용하여 실행 시간 측정
- 실제 시스템의 런타임을 사용하여 성능 추론

# 2. Big O
***
### 정렬
1. Selection Sort
   1. 최선의 경우 O(n^2)
   2. 최악의 경우 O(n^2)
   3. 평균적으로 O(n^2)
2. Insertion Sort
    1. 최선의 경우 O(n)
    2. 최악의 경우 O(n^2)
    3. 평균적으로 O(n^2)
3. Merge Sort
    1. 최선의 경우 O(n log n)
    2. 최악의 경우 O(n log n)
    3. 평균적으로 O(n log n)
4. Quick Sort
    1. 최선의 경우 O(n log n)
    2. 최악의 경우 O(n log n)
    3. 평균적으로 O(n^2)
